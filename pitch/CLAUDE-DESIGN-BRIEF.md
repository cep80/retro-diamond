## How to use this

1. New Claude Design project, **16:9 presentation**.
2. Upload every file in `pitch/art/` (listed below).

4. If it writes “Rise,” “Trainer,” “gacha pull,” or a batting average on the ending still, correct it immediately.
5. Share / Send to Vercel when a deck is ready.

Make **three projects**, not one file with three modes.

## Don'ts (hard)

- Wordmark is **Diamond Shine** / **ダイヤシャイン**. Never Rise. Never Ace of Diamond.
- Baseball. Not softball. No fastpitch mound. No different ball.
- No gacha, banners, rates, stamina gates, login energy, FOMO timers.
- No gym maps, weight rooms, campus RPG tiles.
- No horse ears, carrot jokes, idol 3D concerts. Curtain Call is お立ち台 or a dugout step.
- You are **Coach**, not Trainer. (Trainer = medical, trainer’s room.)
- Six fully written girls. No grey silhouettes.
- Ending still **before** stats. No batting average on the emotional frame.
- Do not invent faces for decks. Use the locked files in `pitch/art/`. When generating *new* stills or video, use [`STYLE.md`](STYLE.md) + [`LOOK.md`](LOOK.md) only — never attach old portraits as face references (they bake same-face).
- Cast identity is locked in [`pitch/LOOK.md`](LOOK.md). Silhouette first: height, hair mass, one inevitable prop. Not hair-color swaps of one athlete.
- **Girls only.** Six young women. Feminine anime faces. No male-presenting cast members.
- **Bat rule:** Curtain Call / お立ち台 = cap in hand, **no bat**. If a still has a bat sticking out of someone’s back, it is retired — do not use it.

## Layout notes for Claude Design

- Full-bleed stills. Type in a cream/gold block at 70–80% opacity ink, not a rainbow of cards.
- Cast slides: **portraits**, black background, name + verb only.
- Quote slides: one quote, huge, attribution none (it is the player fantasy).
- Tables only on P11, I5. Everywhere else, kill the grid.
- Progress ticks, keyboard if the tool supports it.
- Reduced motion: stills may fade; no looping sparkle.
